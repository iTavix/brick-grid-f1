# Brick Grid F1 2026

Il campionato di Formula 1 2026 raccontato con le minifig e le auto LEGO® Speed Champions: classifiche, risultati di ogni GP, Pilota del giorno, calendario e piste, video a 360° dei set e pilota preferito.

App web in stile iOS: si apre nel browser e si può aggiungere alla schermata Home.

Dati di gara: API Jolpica (Ergast). Progetto amatoriale non affiliato a LEGO o Formula 1; immagini e video dei set appartengono a LEGO.
